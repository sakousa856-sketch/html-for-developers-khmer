🌐 មេរៀនទី ០១ - ០៤៖ រចនាសម្ព័ន្ធមូលដ្ឋាន (Basic Structure)

នេះគឺជាឯកសារ HTML ស្តង់ដារពេញលេញមួយ ដែល Browser អាចយល់ និងបង្ហាញបានយ៉ាងត្រឹមត្រូវ។

💡 ចំណាំសម្រាប់សិស្ស៖ រាល់ឯកសារ HTML ត្រូវតែចាប់ផ្តើមដោយ <!DOCTYPE html> ដើម្បីប្រាប់ Browser ថាឯកសារនេះប្រើប្រាស់ស្តង់ដារ HTML5។

១. ធាតុសំខាន់ៗក្នុងឯកសារនេះ (Core Elements)

  • <!DOCTYPE html>: ប្រកាសប្រាប់ Browser ពី Document Type (HTML5)
  • <html lang="km">: Root Element ដែលក្តោបមាតិកាគេហទំព័រទាំងអស់
  • <head>: ផ្ទុកទិន្នន័យសម្គាល់ (Metadata) ដូចជា Title, Charset, Viewport
  • <body>: ផ្ទុកមាតិកាទាំងអស់ដែលត្រូវបង្ហាញលើអេក្រង់ Browser របស់អ្នកប្រើប្រាស់

២. ការបង្ហាញកថាខណ្ឌ និងបន្ទាត់ផ្តេក (Paragraph & Line Break)

កថាខណ្ឌត្រូវបានបង្កើតឡើងដោយប្រើ Tag <p>។
យើងអាចប្រើ Tag <br> ដើម្បីចុះបន្ទាត់ថ្មីដោយមិនចាំបាច់បង្កើតកថាខណ្ឌថ្មី។

៣. ប៊ូតុងសាកល្បង (Interactive Button)

ចុចប៊ូតុងខាងក្រោមដើម្បីសាកល្បង Interaction សាមញ្ញ៖
