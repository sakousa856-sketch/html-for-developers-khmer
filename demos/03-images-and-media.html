រូបភាព និងប្រព័ន្ធផ្សព្វផ្សាយ (Images, Audio, Video & Iframes)

មេរៀននេះបង្ហាញពីការដាក់បញ្ចូលរូបភាព (Image), សំឡេង (Audio), វីដេអូ (Video) និងការបង្កប់ YouTube តាមរយៈ Iframe ដោយប្រើ HTML Tags សុទ្ធ។

១. ការប្រើប្រាស់រូបភាព (HTML Images)

ចំណុចសំខាន់នៃ Tag <img>:

  • src (Source): ទីតាំង URL ឬផ្លូវនៃ file រូបភាព
  • alt (Alternative Text): អត្ថបទពិពណ៌នារូបភាព (សំខាន់សម្រាប់ SEO និង Screen Readers)
  • width និង height: កំណត់ទំហំទទឹង និងកម្ពស់គិតជា Pixel

២. ការចាក់សំឡេង (HTML Audio Player)

ប្រើប្រាស់ Tag <audio controls> ជាមួយ <source>៖

៣. វីដេអូក្នុង HTML (HTML Video Player)

ប្រើប្រាស់ Tag <video controls>៖

៤. ការបង្កប់វីដេអូ YouTube តាម Iframe (YouTube Embed)

ការបង្កប់វីដេអូ YouTube ដោយប្រើ <iframe>៖
