# មេរៀនទី ០៩៖ ទម្រង់អត្ថបទ (HTML Text Formatting)

> **HTML ផ្តល់នូវ Elements ពិសេសៗជាច្រើនសម្រាប់កំណត់រូបរាងអត្ថបទ ដូចជា អក្សរដិត ទ្រេត គូសបន្ទាត់ក្រោម គូសចោល ឬអក្សរតូច/ធំពិសេស។**

---

## ១. បណ្តា Formatting Elements ទាំងអស់ក្នុង HTML

| Tag | ឈ្មោះ និងតួនាទី | អត្ថន័យ Semantic (Meaning) |
| :--- | :--- | :--- |
| `<b>` | Bold Text | អក្សរដិតធម្មតា (គ្មានទម្ងន់ Semantic) |
| `<strong>` | Important Text | អក្សរដិតសំខាន់ខ្លាំង (Screen Readers សង្កត់សំឡេង) |
| `<i>` | Italic Text | អក្សរទ្រេតធម្មតា (ឈ្មោះសៀវភៅ, ពាក្យបច្ចេកទេស) |
| `<em>` | Emphasized Text | អក្សរទ្រេតសង្កត់ន័យ |
| `<mark>` | Marked/Highlighted Text | អក្សរដែលមាន Highlight ពណ៌លឿង |
| `<small>` | Smaller Text | អក្សរទំហំតូច (Copyright, Disclaimer) |
| `<del>` | Deleted Text | អក្សរដែលមានបន្ទាត់គូសឆូតចោល |
| `<ins>` | Inserted Text | អក្សរដែលមានបន្ទាត់គូសពីក្រោម (តម្លៃថ្មី) |
| `<sub>` | Subscript Text | អក្សរស្ថិតនៅខាងក្រោមជួរ (រូបមន្តគីមី H<sub>2</sub>O) |
| `<sup>` | Superscript Text | អក្សរស្ថិតនៅខាងលើជួរ (ស្វ័យគុណ X<sup>2</sup>) |

---

## ២. ភាពខុសគ្នារវាង `<b>` vs `<strong>` និង `<i>` vs `<em>`

* **`<b>` vs `<strong>`:**  
  ផ្ទាំង Browser បង្ហាញអក្សរដិតដូចគ្នាទាំងពីរ ប៉ុន្តែ `<strong>` មានន័យថាអត្ថបទនោះមានសារៈសំខាន់ខ្ពស់ (SEO & Accessibility ផ្តល់អាទិភាពដល់ `<strong>`)។
* **`<i>` vs `<em>`:**  
  Browser បង្ហាញអក្សរទ្រេតដូចគ្នា ប៉ុន្តែ `<em>` បង្ហាញពីការសង្កត់សំឡេងលើពាក្យនោះពេល Screen Reader អាន។

---

## ៣. ឧទាហរណ៍កូដជាក់ស្តែង (Code Example)

```html
<p>
  កុំព្យូទ័រនេះមានតម្លៃពិសេស 
  <del>$1,200</del> នៅសល់ត្រឹមតែ <ins><strong>$999</strong></ins> ប៉ុណ្ណោះ!
</p>

<p>
  រូបមន្តគីមីនៃជាតិស្ករគ្លុយកូសគឺ <b>C<sub>6</sub>H<sub>12</sub>O<sub>6</sub></b>។
</p>

<p>
  ទ្រឹស្តីបទពីតាករ៖ <i>a<sup>2</sup> + b<sup>2</sup> = c<sup>2</sup></i>
</p>
```

## ✍️ លំហាត់អនុវត្តសម្រាប់សិស្ស (Practice Exercises)

1. ចូរសរសេរសមីការគណិតវិទ្យា `(x + y)² = x² + 2xy + y²` ឱ្យបានត្រឹមត្រូវដោយប្រើ `<sup>`។
2. ចូរបង្កើតកថាខណ្ឌមួយដែលបង្ហាញពីការបញ្ចុះតម្លៃទំនិញ ដោយប្រើ `<del>`, `<ins>`, និង `<mark>`។
