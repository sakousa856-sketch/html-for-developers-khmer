# មេរៀនទី ០៧៖ កថាខណ្ឌ និងការចុះបន្ទាត់ (HTML Paragraphs & Line Breaks)

> **Tag `<p>` ត្រូវបានប្រើសម្រាប់កំណត់កថាខណ្ឌអត្ថបទ ហើយ Browser នឹងបន្ថែមគម្លាត (Margin) លើ-ក្រោមដោយស្វ័យប្រវត្តិ។**

---

## ១. ការប្រើប្រាស់ Tag `<p>` (HTML Paragraphs)

```html
<p>នេះគឺជាកថាខណ្ឌទីមួយ។</p>
<p>នេះគឺជាកថាខណ្ឌទីពីរ។ Browser នឹងបង្កើតគម្លាតមួយរវាងកថាខណ្ឌទាំងពីរនេះ។</p>
```

---

## ២. បញ្ហាគម្លាត និងការចុះបន្ទាត់ក្នុង HTML (White Space Collapse)

នៅក្នុង HTML ប្រសិនបើអ្នកចុះបន្ទាត់ច្រើនដង ឬដកឃ្លា (Spaces) ច្រើនដងក្នុងកូដ Browser នឹងបង្រួមវាឱ្យនៅសល់តែ **ដកឃ្លាមួយ (Single Space)** ប៉ុណ្ណោះ៖

```html
<!-- កូដដែលសរសេរ -->
<p>
  អត្ថបទនេះ     មានដកឃ្លាច្រើន 
  
  និងចុះបន្ទាត់ច្រើន។
</p>

<!-- លទ្ធផលដែល Browser បង្ហាញគឺ៖ "អត្ថបទនេះ មានដកឃ្លាច្រើន និងចុះបន្ទាត់ច្រើន។" -->
```

---

## ៣. ការដោះស្រាយបញ្ហាគម្លាត និងចុះបន្ទាត់

### ១. ប្រើប្រាស់ `<br>` (Line Break)
ប្រើសម្រាប់ចុះបន្ទាត់ថ្មីក្នុងកថាខណ្ឌតែមួយ (មិនបន្ថែម Margin ធំដូច `<p>` ថ្មីទេ)៖
```html
<p>
  ផ្លូវលេខ ២៧១ រាជធានីភ្នំពេញ<br>
  ទូរស័ព្ទ៖ 012 345 678<br>
  អ៊ីមែល៖ info@example.com
</p>
```

### ២. ប្រើប្រាស់ `<hr>` (Horizontal Rule)
បង្កើតបន្ទាត់ផ្តេកសម្រាប់ខណ្ឌចែកផ្នែកនៃអត្ថបទ៖
```html
<h2>ជំពូកទី ១</h2>
<p>ខ្លឹមសារជំពូកទី ១...</p>
<hr>
<h2>ជំពូកទី ២</h2>
<p>ខ្លឹមសារជំពូកទី ២...</p>
```

### ៣. ប្រើប្រាស់ `<pre>` (Preformatted Text)
Tag `<pre>` រក្សាទុក **គម្លាត Spaces និងការចុះបន្ទាត់ទាំងអស់** ដូចគ្នានឹងអ្វីដែលអ្នកបានសរសេរក្នុងកូដ ហើយបង្ហាញជាពុម្ពអក្សរ Monospace៖
```html
<pre>
  កំណាព្យ ឬ កូដកុំព្យូទ័រ៖
    ជួរទី ១: សួស្តី
    ជួរទី ២:   ដកឃ្លាខាងក្នុង
</pre>
```

## ✍️ លំហាត់អនុវត្តសម្រាប់សិស្ស (Practice Exercises)

1. តើ Browser ធ្វើអ្វីខ្លះនៅពេលដែលយើងដកឃ្លា ៥ ដងជាប់គ្នាក្នុង Tag `<p>`?
2. ចូរសរសេរអាសយដ្ឋានផ្ទះរបស់អ្នកដោយប្រើ `<p>` និង `<br>` ឱ្យបានស្អាតត្រឹមត្រូវ។
3. ប្រើប្រាស់ Tag `<pre>` ដើម្បីសរសេរកំណាព្យ ឬអត្ថបទដែលមានទម្រង់ដកឃ្លាពិសេសមួយ។
