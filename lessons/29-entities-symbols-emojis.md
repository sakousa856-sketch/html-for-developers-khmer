# មេរៀនទី ២៩៖ តួអក្សរពិសេស និមិត្តសញ្ញា និង Emoji (HTML Entities, Symbols & Emojis)

> **តួអក្សរដែលបានបម្រុងទុក (Reserved Characters) ក្នុង HTML (ដូចជា `<` និង `>`) មិនអាចសរសេរដោយផ្ទាល់បានទេ ព្រោះ Browser នឹងច្រឡំថាជា HTML Tag។ យើងត្រូវប្រើប្រាស់ HTML Entities ជំនួសវិញ។**

---

## ១. បណ្តា HTML Entities ដែលប្រើញឹកញាប់បំផុត

| តួអក្សរ (Char) | ឈ្មោះ Entity Name | លេខកូដ Entity Number | ការពិពណ៌នា (Description) |
| :---: | :--- | :--- | :--- |
| `<` | `&lt;` | `&#60;` | តូចជាង (Less than) |
| `>` | `&gt;` | `&#62;` | ធំជាង (Greater than) |
| `&` | `&amp;` | `&#38;` | សញ្ញា And (Ampersand) |
| `"` | `&quot;` | `&#34;` | សញ្ញាសម្រង់ទ្វេ (Double quote) |
| `'` | `&apos;` | `&#39;` | សញ្ញាសម្រង់ទោល (Single quote) |
| ` ` | `&nbsp;` | `&#160;` | ដកឃ្លាមិនបំបែកបន្ទាត់ (Non-breaking space) |
| `©` | `&copy;` | `&#169;` | សញ្ញាកម្មសិទ្ធិ (Copyright) |
| `®` | `&reg;` | `&#174;` | សញ្ញាពាណិជ្ជសញ្ញា (Registered Trademark) |
| `€` | `&euro;` | `&#8364;` | សញ្ញារូបិយប័ណ្ណអឺរ៉ូ (Euro) |
| `¥` | `&yen;` | `&#165;` | សញ្ញាប្រាក់យ៉េន (Yen) |

### ឧទាហរណ៍៖
```html
<!-- បង្ហាញកូដ HTML លើអេក្រង់ដោយមិនឱ្យ Browser ច្រឡំ -->
<p>ដើម្បីសរសេរកថាខណ្ឌ យើងត្រូវប្រើ Tag &lt;p&gt; និង &lt;/p&gt;។</p>
<p>&copy; 2026 រក្សាសិទ្ធិគ្រប់យ៉ាង។</p>
```

## ២. និមិត្តសញ្ញាគណិតវិទ្យា និងព្រួញ (Symbols & Arrows)

* ព្រួញឆ្វេង (`←`): `&larr;`
* ព្រួញស្តាំ (`→`): `&rarr;`
* សញ្ញាផលបូក (`∑`): `&sum;`
* សញ្ញាអនន្ត (`∞`): `&infin;`
* សញ្ញាមិនស្មើ (`≠`): `&ne;`

---

## ៣. ការប្រើប្រាស់ Emoji ក្នុង HTML (HTML Emojis)

Emojis គឺជាតួអក្សរពីតារាង **UTF-8 (Unicode)**។ យើងអាចសរសេរ Emoji ដោយផ្ទាល់ ឬប្រើប្រាស់ Unicode Entity Number របស់វា៖

```html
<!DOCTYPE html>
<html lang="km">
<head>
  <meta charset="UTF-8">
</head>
<body>
  <!-- សរសេរផ្ទាល់ -->
  <p>សួស្តីកម្ពុជា! 🇰🇭 🚀 💻 ☕</p>

  <!-- ឬប្រើប្រាស់ Unicode Hex/Dec Number -->
  <p>មុខញញឹម៖ &#128512; | ភ្លើង៖ &#128293; | បេះដូង៖ &#10084;&#65039;</p>
</body>
</html>
```
