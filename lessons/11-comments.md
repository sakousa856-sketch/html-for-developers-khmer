# មេរៀនទី ១១៖ ការដាក់ចំណាំក្នុងកូដ (HTML Comments)

> **HTML Comments ត្រូវបានប្រើដើម្បីកត់ត្រាចំណាំក្នុងកូដ ជួយឱ្យ Developer ងាយយល់ និងសម្រាប់លាក់កូដបណ្តោះអាសន្នពេលកំពុង Debug។**

---

## ១. ទម្រង់សរសេរ Comment ក្នុង HTML

Comment ក្នុង HTML ចាប់ផ្តើមដោយ `<!--` និងបញ្ចប់ដោយ `-->`៖

```html
<!-- នេះគឺជា Comment ក្នុង HTML -->
<p>អត្ថបទនេះនឹងត្រូវបង្ហាញលើ Browser។</p>
<!-- កថាខណ្ឌខាងក្រោមត្រូវបានលាក់បណ្តោះអាសន្ន
<p>អត្ថបទនេះមិនបង្ហាញលើ Browser ឡើយ។</p>
-->
```

---

## ២. គោលបំណងចម្បងនៃការប្រើប្រាស់ Comments

1. **កត់ត្រាពន្យល់កូដ (Documentation):** ជួយឱ្យសមាជិកក្នុងក្រុម ឬខ្លួនយើងផ្ទាល់នៅពេលក្រោយ ងាយយល់ពីគោលបំណងនៃផ្នែកនីមួយៗក្នុងកូដ។
2. **បែងចែកផ្នែកនៃកូដ (Section Demarcation):**
   ```html
   <!-- ==================== HEADER SECTION ==================== -->
   <header>
     <h1>Logo គេហទំព័រ</h1>
   </header>

   <!-- ==================== MAIN CONTENT ==================== -->
   <main>
     <p>ខ្លឹមសារចម្បង...</p>
   </main>

   <!-- ==================== FOOTER SECTION ==================== -->
   <footer>
     <p>&copy; 2026</p>
   </footer>
   ```
3. **Debug កូដ:** លាក់កូដដែលសង្ស័យថាមានបញ្ហាដោយមិនចាំបាច់លុបវាចោល។

> ⚠️ **ការព្រមានសុវត្ថិភាព (Security Warning):**  
> ទោះបីជា Comment មិនបង្ហាញលើផ្ទាំងគេហទំព័រក៏ដោយ ប៉ុន្តែអ្នកប្រើប្រាស់ណាក៏អាចមើលឃើញ Comment ទាំងនោះបានដែរតាមរយៈការចុច **View Page Source (Ctrl + U / Cmd + Option + U)** ក្នុង Browser។ ដូច្នេះ **កុំដាក់ Password, API Keys ឬព័ត៌មានសម្ងាត់ក្នុង HTML Comments ជាដាច់ខាត!**
