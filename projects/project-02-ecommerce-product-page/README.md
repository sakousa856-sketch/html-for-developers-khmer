# 🏆 Capstone Project 02: ទំព័រផលិតផលពាណិជ្ជកម្មអេឡិចត្រូនិច (E-Commerce Product Showcase)

## 📌 សេចក្តីផ្តើមនៃគម្រោង (Project Overview)
គម្រោងនេះជាការសាងសង់ទំព័របង្ហាញព័ត៌មានលម្អិតនៃផលិតផល (Product Detail Page) សម្រាប់គេហទំព័រ E-Commerce ដោយផ្តោតលើ Semantic Tags, Product Gallery, Price Formatting, Reviews Table, Add to Cart Form, និង Shopping Cart Storage។

---

## 📋 លក្ខណៈពិសេសដែលត្រូវមាន (Key Features)
1. **Product Gallery:** បង្ហាញរូបភាពធំ និងរូបភាពតូចៗ Thumbnail សម្រាប់ចុចផ្លាស់ប្តូររូបភាព។
2. **Product Details & Badges:** ឈ្មោះផលិតផល ផ្កាយ Review ការបញ្ចុះតម្លៃ (`<del>` និង `<ins>`)។
3. **Product Options Form:** ជ្រើសរើសទំហំ (Radio / Select), ពណ៌ (Color Swatches), និងចំនួនទិញ (Quantity Input `min="1"` `max="10"`).
4. **Product Specifications Table:** តារាងលក្ខណៈបច្ចេកទេសលម្អិតនៃទំនិញ។
5. **Customer Reviews Section:** ការវាយតម្លៃ និង Form បញ្ចេញមតិ។
