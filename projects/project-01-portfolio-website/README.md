# 🏆 Capstone Project 01: គេហទំព័រ Portfolio ផ្ទាល់ខ្លួនពេញលេញ (Personal Developer Portfolio)

## 📌 សេចក្តីផ្តើមនៃគម្រោង (Project Overview)
គម្រោងនេះគឺជាការអនុវត្តសាងសង់គេហទំព័រ Portfolio ផ្ទាល់ខ្លួនពេញលេញមួយតាំងពីក្បាលដល់ចុង ដោយប្រើប្រាស់នូវចំណេះដឹង HTML5 ទាំងអស់ដែលបានរៀនកន្លងមក (Semantic Layout, Formatting, Images, Video/Audio, Tables, Lists, Iframes, Forms, និង JavaScript)។

---

## 📋 លក្ខណៈពិសេសដែលត្រូវមាន (Key Features)
1. **Hero Section:** បង្ហាញរូប Profile, ឈ្មោះ, តួនាទី និងពាក្យស្លោកផ្ទាល់ខ្លួន។
2. **About Me Section:** ជីវប្រវត្តិសង្ខេប ការអប់រំ និងទស្សនវិស័យការងារ។
3. **Skills & Experience Section:** តារាងជំនាញបច្ចេកទេស និងបញ្ជីស្នាដៃ Project ធ្លាប់ធ្វើ។
4. **Interactive Video Showcase:** វីដេអូ ឬ Iframe បង្ហាញពីគម្រោង Demo។
5. **Contact Form:** ទម្រង់សម្រាប់ភ្ញៀវផ្ញើសារ ឬទាក់ទងការងារ ជាមួយ Input Validations ពេញលេញ។
6. **Dark/Light Mode Toggle:** ប្រើប្រាស់ `localStorage` សម្រាប់ចងចាំ Theme។

---
