# 📝 លំហាត់អនុវត្តទី ០៤៖ បង្កើតប្លង់គេហទំព័រព័ត៌មាន (News/Blog Semantic Layout)

## 🎯 គោលបំណង (Objective)
អនុវត្តការប្រើប្រាស់ Semantic HTML5 Elements ក្នុងការសាងសង់គ្រោងឆ្អឹងគេហទំព័របែបព័ត៌មាន/ប្លក់ស្អាតត្រឹមត្រូវតាមស្តង់ដារ W3C និង SEO។

---

## 📋 លក្ខខណ្ឌតម្រូវ (Requirements)
សិស្សត្រូវបង្កើត File ឈ្មោះ `blog.html` ដោយមានបញ្ចូលចំណុចដូចខាងក្រោម៖
1. **`<header>`:** មាន Logo គេហទំព័រ ចំណងជើងធំ និងពាក្យស្លោក (Slogan)។
2. **`<nav>`:** មានបញ្ជីរាយ Menu (ទំព័រដើម, ព័ត៌មានជាតិ, អន្តរជាតិ, បច្ចេកវិទ្យា, អំពីយើង)។
3. **`<main>`:** ផ្ទុកមាតិកាស្នូលដោយចែកជា ២ ផ្នែក៖
   * `<section id="top-news">`: ផ្ទុក `<article>` ព័ត៌មានសំខាន់ៗយ៉ាងតិច ២ អត្ថបទ ដោយក្នុងនោះមាន `<header>` (ចំណងជើង និងកាលបរិច្ឆេទ `<time>`), `<figure>` និង `<figcaption>`, និងខ្លឹមសារកថាខណ្ឌ។
4. **`<aside>`:** ផ្នែក Sidebar ដែលមានព័ត៌មានពេញនិយម (Popular Posts) និងតំណភ្ជាប់បណ្តាញសង្គម។
5. **`<footer>`:** ផ្នែកខាងក្រោមបង្អស់ដែលមានព័ត៌មានរក្សាសិទ្ធិ `&copy; 2026` និងអាសយដ្ឋានទំនាក់ទំនង `<address>`។
