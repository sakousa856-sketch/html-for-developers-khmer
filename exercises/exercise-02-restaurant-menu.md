# 📝 លំហាត់អនុវត្តទី ០២៖ បង្កើតតារាងម៉ឺនុយភោជនីយដ្ឋាន (Restaurant Menu Table)

## 🎯 គោលបំណង (Objective)
អនុវត្តការសាងសង់តារាង HTML Tables ស្មុគស្មាញដោយប្រើប្រាស់ `<thead>`, `<tbody>`, `<tfoot>`, `<th>`, `<td>`, `colspan`, និង `rowspan`។

---

## 📋 លក្ខខណ្ឌតម្រូវ (Requirements)
សិស្សត្រូវបង្កើត File ឈ្មោះ `menu.html` ដោយមានបញ្ចូលចំណុចដូចខាងក្រោម៖
1. **ចំណងជើងហាង (`<h1>`):** ឈ្មោះភោជនីយដ្ឋាន ឬហាងកាហ្វេ។
2. **តារាងទិន្នន័យ (`<table>`):**
   * មាន `<caption>` បញ្ជាក់ចំណងជើងតារាង "ម៉ឺនុយម្ហូប និងភេសជ្ជៈប្រចាំថ្ងៃ"
   * `<thead>`: មានជួរចំណងជើង (ប្រភេទ, ឈ្មោះមុខម្ហូប/ភេសជ្ជៈ, ទំហំ/ខ្នាត, តម្លៃ)
   * `<tbody>`: រាយមុខម្ហូបយ៉ាងតិច ៦ មុខ ដោយប្រើ `rowspan` សម្រាប់ក្រុមប្រភេទមុខម្ហូប (ឧ. ក្រុម "កាហ្វេ", ក្រុម "បាយ/គុយទាវ")
   * `<tfoot>`: មានជួរព័ត៌មានពិសេស ដោយប្រើ `colspan` ក្តោប ៤ ជួរឈរ (ឧ. "បញ្ជាក់៖ រាល់ការទិញលើសពី $10 ថែមជូនភេសជ្ជៈ ១ កែវឥតគិតថ្លៃ")
3. **ការតុបតែង Style សាមញ្ញ:** ដាក់ `border-collapse: collapse;`, ពណ៌ Header, និង Hover effect លើ Table rows។
